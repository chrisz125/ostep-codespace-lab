# OSTEP Ch.4 Homework Answers
## Q1
- Prediction / 预测: Total time = 10, CPU utilization = 100%
- Reasoning / 理由: Both processes only use the CPU, so the CPU is never idle.
- Verified result / 验证结果:Total time = 10, CPU Busy = 10 (100%)
- Analysis / 分析: Prediction matched. Both processes are CPU-only, so the CPU runs for 10 ticks with no idle time.

## Q2

- Prediction / 预测: Total time = 11, CPU utilization = 6/11 ≈ 54.5%
- Reasoning / 理由: PID 0 runs 4 CPU ticks first, then PID 1 does one I/O (7 ticks). CPU idle while PID 1 is blocked.
- Verified result / 验证结果:Total time = 11, CPU Busy = 6 (54.55%)
- Analysis / 分析:Prediction matched. PID 0 finishes at time 4, then PID 1 does its I/O; the CPU is idle for 5 ticks while PID 1 is blocked.
    

## Q3

- Prediction / 预测: Total time = 7, CPU utilization = 6/7 ≈ 85.7%
- Reasoning / 理由: PID 0 issues I/O first, so system switches to PID 1. PID 1 uses the CPU while PID 0 is blocked.
- Verified result / 验证结果:Total time = 7, CPU Busy = 6 (85.71%)
- Analysis / 分析: Prediction matched. Switching on I/O lets PID 1 use the CPU while PID 0 is blocked, so only 1 tick is idle.

## Q4

- Prediction / 预测: Total time = 11, CPU utilization = 6/11 ≈ 54.5%
- Reasoning / 理由: SWITCH_ON_END means the OS doesn't switch on I/O. PID 1 waits until PID 0 finishes, so CPU is idle for 5 ticks.
- Verified result / 验证结果:Total time = 11, CPU Busy = 6 (54.55%)
- Analysis / 分析:- Prediction matched. SWITCH_ON_END keeps PID 1 waiting until PID 0 finishes, so the CPU is idle for 5 ticks and total time is longer than Q3.
